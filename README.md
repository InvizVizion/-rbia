# RBIA — Информационный портал «Российский бизнес в Африке»

Современный, удобный информационный портал для российского бизнеса, выходящего на
рынки Африки. Особый фокус — **Танзания** (Восточная Африка) и **Западная Африка**
(Нигерия, Гана, Сенегал, Кот-д'Ивуар и др.).

Развивается совместно с **АНО «ДМТК»** и **Российско-Африканским деловым советом**.

## Что внутри

| Страница | Файл | Назначение |
|----------|------|------------|
| Главная | `index.html` | Обзор портала, ключевые цифры, приоритетные рынки, навигация |
| Проекты | `projects.html` | Действующие и планируемые бизнес-проекты с фильтром по стране/отрасли |
| Направления | `sectors.html` | Перспективные отрасли + матрица потенциала по рынкам |
| Нормативка | `regulation.html` | Регистрация, налоги, валютный контроль, таможня (Танзания и ECOWAS) |
| О портале | `about.html` | Миссия, принципы, партнёры |
| Контакты | `contacts.html` | Форма заявки и прямые контакты |

## Технологии

Чистый статический сайт — **HTML + CSS + ванильный JS**, без сборки и зависимостей.
Подключается только шрифт Manrope с Google Fonts.

- `assets/css/styles.css` — единая дизайн-система (CSS-переменные, компоненты, адаптив)
- `assets/js/main.js` — мобильное меню, аккордеон, фильтры, анимации появления, форма

Сайт адаптивен (desktop / tablet / mobile) и работает в любом современном браузере.

## Запуск локально

Просто откройте `index.html` в браузере, либо поднимите статический сервер:

```bash
python3 -m http.server 8000
# затем откройте http://localhost:8000
```

## Деплой

Подходит для любого статического хостинга. Для GitHub Pages: включите Pages в
настройках репозитория с источником из этой ветки (корень `/`).

## Важно

- Данные о проектах, цифрах и нормативке носят **справочный характер** и подлежат
  проверке на дату сделки. Это не юридическая или инвестиционная рекомендация.
- Форма обратной связи на странице «Контакты» — демонстрационная. Для приёма
  заявок подключите почтовый сервис (например, Formspree) или CRM.
- Контактные данные (`info@rbia.example`, телефон) — заглушки, замените на реальные.
